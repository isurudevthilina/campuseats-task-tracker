# CampusEats Task Tracker

A small team repository for the CampusEats developers to track work and practise
the full Git/GitHub collaboration workflow: branch -> commit -> pull request ->
review -> merge, with Issues for planning and GitHub Actions checking every change.

## Structure
- `src/tasks.js` - a small sample file used to demonstrate the workflow
- `.github/workflows/ci.yml` - the CI pipeline (build/check on every push and PR)
